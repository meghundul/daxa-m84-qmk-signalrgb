## [1.0.0] - 2024-01-01

### Added
- Initial release
- QMK firmware for Rexus Daxa M84 Ultimate (SN32F248BF)
- SignalRGB Raw HID protocol: Enable (0x01), Color Data (0x02), Sync (0x03), Disable (0x04)
- Hardware GRB channel correction with per-channel luminance calibration
- Caps Lock white LED indicator override
- FN layer: media keys, RGB matrix controls, Win-lock, AG-swap, QK_BOOT
- NKRO enabled
- SignalRGB device plugin v1.1.9
- GitHub Actions CI workflow
